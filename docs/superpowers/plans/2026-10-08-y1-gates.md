# Y1 两道闸门 实施计划（DDR 带宽 R1 + 面积 G1）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用两个便宜、独立的闸门判定「自研 8×8 分组卷积加速器 + 逐层特征落 DDR」这条线是否成立 —— ① 本板 DDR 有效带宽够不够（spec R1）；② 一个**代表性切片**的面积在不在 G1 预算内。

**Architecture:** **Part A** 先用本仓 DDR3 IP/胶合的**静态上界**（用户口位宽 × `core_clk`）做算术否决，再在板端跑**用户态实测**（缓冲区 ≫ cache、字宽访问、读/写分列），并用**缓存负对照**证明测法能区分 DRAM 与 cache；若结果落在边界附近，升级为 AXI 主口微基准（需上板，红线）。**Part B** 搭一个自含的 **3×3 分组卷积代表性切片**（8×8 int8 阵列 + 行缓冲 + 权重存储 + 简单控制），数值用 iverilog 对 Python 参考（含 dense / depthwise / group=4 三档），面积跑 PDS `dev_map` 对照 G1。

**Tech Stack:** SpinalHDL 1.15.0 / Scala 2.12.18 + sbt（本机 runner 2.0.6，声明 1.10.0，JDK 17）；`iverilog`（B8 已证实可用）；PDS 2025.2 `dev_map`；板端 Linux 用户态（`clock_gettime(CLOCK_MONOTONIC)`）。

**Spec:** `docs/superpowers/specs/2026-10-08-yunet-accelerator-small-design.md`

## 为什么不写整个 Y1 核心（范围说明）

spec 的 Y1–Y5 是多个独立子系统；本计划只覆盖**前两道闸门**，因为：
- **R1 未定**时，DDR 范式可能要从"逐层落 DDR"改成"层融合"，那会把指令编码/控制 FSM/行缓冲管理整体推翻 ⇒ 先写死整核会大量返工。
- G1 用**代表性切片**（面积占比最大的三件：阵列、行缓冲、权重存储）就能判，不必先有完整控制。
- Y3（转换器+运行时）、Y5（相机接入）各自另出计划。

```python
"""由用户口位宽与频率算 DDR 的静态上界。
用法: ddr_ceiling.py <port_bytes> <freq_hz> [efficiency ...]
输出：raw 上界与按若干效率系数的可达估计，并给出对 R1 需要的 305/458 MB/s 的判定。
"""
import sys
sys.stdout.reconfigure(errors="replace")
W = float(sys.argv[1])          # 用户口字节数/拍
f = float(sys.argv[2])          # Hz
raw = W * f
print(f"user port = {W:g} B/beat @ {f/1e6:g} MHz -> raw ceiling {raw/1e6:.1f} MB/s")
need_15 = 30.5 * 1e6 * 15       # 30.5 MB/帧 @15fps
need_10 = 30.5 * 1e6 * 10
for eff in [float(x) for x in sys.argv[3:]] or [0.5, 0.6, 0.7, 0.8]:
    ach = raw * eff
    v15 = "OK" if ach >= need_15 else "NO"
    v10 = "OK" if ach >= need_10 else "NO"
    print(f"  eff={eff:.1f} -> {ach/1e6:7.1f} MB/s | @15fps(458 MB/s): {v15} | @10fps(305 MB/s): {v10}")
print(f"需要: @15fps {need_15/1e6:.0f} MB/s ; @10fps {need_10/1e6:.0f} MB/s")
```

- [ ] **Step 1: 写参考模型（dense / depthwise / group=N 三档）**

```python
"""3x3 int8 卷积的整数参考。三种模式：
  dense    : group=1
  dw       : group=C_in=C_out（深度可分离）
  grouped  : group=G（C_in 与 C_out 都能被 G 整除）
约定：padding=1、stride=1、int8 输入/权重、int32 累加、输出 requant 到 int8（scale 由 shape 决定，测试里用 1 与移位）。
用法: mac_ref.py <mode> <C_in> <C_out> <H> <W> <seed>  -> 打印输入/权重/输出（十六进制逐元素，供 Verilog 装置消费）
"""
import sys, random
sys.stdout.reconfigure(errors="replace")

def conv3x3(mode, cin, cout, h, w, seed):
    rnd = random.Random(seed)
    x = [[[rnd.randint(-128, 127) for _ in range(w)] for _ in range(h)] for _ in range(cin)]
    g = cin if mode == "dw" else (int(mode.split("=")[1]) if mode.startswith("group=") else 1)
    if mode == "dw":
        cout = cin
    assert cin % g == 0 and cout % g == 0, "通道数必须能被 group 整除"
    wt = [[[rnd.randint(-128, 127) for _ in range(3)] for _ in range(3)] for _ in range(cout * (cin // g))]
    out = [[[0] * w for _ in range(h)] for _ in range(cout)]
    for co in range(cout):
        gi = (co * g) // cout          # 该输出通道属于哪个组
        for y in range(h):
            for xx in range(w):
                acc = 0
                for ci in range(gi * (cin // g), (gi + 1) * (cin // g)):
                    for ky in range(3):
                        for kx in range(3):
                            yy, xxx = y + ky - 1, xx + kx - 1
                            if 0 <= yy < h and 0 <= xxx < w:
                                acc += x[ci][yy][xxx] * wt[co * (cin // g) + (ci - gi * (cin // g))][ky][kx]
                out[co][y][xx] = max(-128, min(127, acc >> 6))   # 测试用的固定 requant 口径
    return x, wt, out

if __name__ == "__main__":
    mode = sys.argv[1]; cin = int(sys.argv[2]); cout = int(sys.argv[3])
    h = int(sys.argv[4]); w = int(sys.argv[5]); seed = int(sys.argv[6])
```

- [ ] **Step 1: 写 `MacArray`（8 输入通道 × 8 输出通道，一拍 64 个 MAC）**

```scala
import spinal.core._

/** 8(C_in) x 8(C_out) int8 MAC 阵列。
  * 一拍：给 8 个输入通道的同一像素 + 8 个输出通道的 3x3 权重切片，产出 8 个 int32 部分和。
  * 分组卷积在 B3 里靠"只喂同组的通道、其余喂 0"实现，不改本模块结构。
  */
class MacArray extends Component {
  val io = new Bundle {
    val x = in  Vec (SInt(8 bits), 8)      // 8 个输入通道的当前像素
    val w = in  Vec (SInt(8 bits), 8)      // 8 个输出通道的当前权重（同一 (ky,kx)）
    val p = out Vec (SInt(32 bits), 8)     // 8 个部分和（寄存器）
  }
  noIoPrefix()
  val acc = Vec(Reg(SInt(32 bits)) init(0), 8)
  for (co <- 0 until 8) {
    // 64 个乘法器的"竖列"之一：8 个输入 × 1 个输出
    val prod = Vec((0 until 8).map(ci => (io.x(ci) * io.w(co)).resize(32)), 8)
    acc(co) := acc(co) + prod.reduce(_ + _)
  }
  io.p := acc
  def clear(): Unit = acc.foreach(_ := 0)   // 供上层在层/像素边界清零
}
```

```scala
import spinal.core._

/** 分组卷积的通道掩码与索引映射。
  * group=1  : 全部 8 个输入通道参与
  * group=G  : 第 co 个输出通道只吃它所属组的那 cin/G 个输入通道
  * dw       : C_in=C_out 且 group=C_in ⇒ 每个输出通道只吃 1 个输入通道
  * 本模块只输出"哪些通道有效"与"输出通道到组的映射"，乘法器本体在 MacArray 里。
  */
case class GroupMask(C_IN: Int, C_OUT: Int, GROUP: Int) extends Area {
  require(C_IN % GROUP == 0 && C_OUT % GROUP == 0, "通道数必须能被 group 整除")
  def groupOfOutChannel(co: Int): Int = (co * GROUP) / C_OUT
  def groupOfInChannel(ci: Int): Int  = (ci * GROUP) / C_IN
  def maskFor(co: Int, ci: Int): Bool = Bool(groupOfOutChannel(co) == groupOfInChannel(ci))
}
```
