> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Y1 核心的两块**前置且可独立验收**的工作做完 —— ① 用 YuNet 的 ONNX 图算出**调度策略下的 DDR 流量**，判定能否 ≤27.6 MB/帧（= 现有桥 275.9 MB/s 下的 10 fps 档）；② 做出加速器的**主机寄存器层**（AxiLite4 从口 + 寄存器表），使核心可被编程。

## 为什么要先做 C0（范围说明，不是拖延）

Y1 核心的**调度器要不要做层融合**，取决于 DDR 流量预算能否压到 **≤27.6 MB/帧**：

- A3-static 已静态钉死：现在进 DDR 的唯一通路 `DDR3Bridge` = **275.9 MB/s**（6 拍@100 MHz + 7 拍@125 MHz = 116 ns / 32 B，单 outstanding + 每笔 AW 只 1 个 beat）。
- 现基线流量 **30.5 MB/帧**（"每层激活都 DDR 往返"）⇒ 275.9/30.5 = **9.04 fps ⇒ 差 9.5%**。
- 若把流量压到 ≤27.6 MB/帧 ⇒ 现有桥就够 10 fps；若不动流量又想上 15 fps，则必须走**直连主口**（raw 4000 MB/s，但要新增 master/仲裁器，且 IP 内部加密 ⇒ 可达需上板实测）。

**这是一个离线、便宜、且会决定后续微架构的判据**。先算它，能避免把调度器写死在错误的分支上。

**本计划的 C0 + C1 互不依赖**，可分别执行。

- [ ] **Step 1: 定义寄存器表（冻结为代码里的单一来源）**

最小可用集（够跑"单层可编程"）：
```
0x00  CTRL        RO/WO  : bit0 start(WO 自清), bit1 soft_reset(WO), bit8 busy(RO), bit9 done(RO)
0x04  STATUS      RO     : bit0 done_sticky(写1清), bit1 err
0x08  IMG_W       RW     : 输入图宽
0x0C  IMG_H       RW     : 输入图高
0x10  C_IN        RW     : 输入通道数
0x14  C_OUT       RW     : 输出通道数
0x18  GROUP       RW     : 分组数
0x1C  KERNEL      RW     : bit0 stride(0=1,1=2), bit1 pad(0/1)
0x20  SRC_ADDR    RW     : 输入特征在 DDR 的地址（32 位）
0x24  DST_ADDR    RW     : 输出特征在 DDR 的地址（32 位）
0x28  QUANT_SHIFT RW     : 输出量化右移位数（算术）
0x2C  LAYER_ID    RW     : 当前层号（调试/遥测）
0x30  ID          RO     : 常量 0x594E5031（"YNP1"），用来证明从口活着
```

- [ ] **Step 2: 写 `HostRegs.scala`**

要点（每条都有理由）：
- **AxiLite4 从口**（32 位地址/数据），用 SpinalHDL 的 `AxiLite4SlaveFactory`（或 `BusSlaveFactory`）建表 —— 与 `ai_npu_exp` 里那个第三方加速器的从口同构，便于复用既有连接方式；
- **`ID` 是常量只读**，作为"从口活着"的第一判据；
- **每一格都导出成一个 typed 输出信号**（`start`/`soft_reset`/`busy`/`done_sticky`/…），供后续任务直接接调度器；
- **不做地址译码之外的事**（不放 FIFO、不放状态机），保持这一片可独立验收；
- 时钟/复位按本工程的约定（`soc_clk` 域、同步高有效复位）。

- [ ] **Step 3: 写装置 `HostRegsTb.v`（Verilog）与门禁 `run_hostregs_ab.sh`**

TB 要点：实现一个最小的 AxiLite4 主控（写一格、读一格），支持从 `+VECFILE=` 读一组"地址 值"向量，打印每格读回值，并在末尾打 `RESULT: PASS|FAIL`（非 0 退出）。**必须暴露 `ID` 的读回**。

门禁 `run_hostregs_ab.sh` 三件事：
1. **穷举回读**：对寄存器表每一格写一个**互不相同**的模式（用地址参与的公式，避免撞值），逐个读回比对，打 `MISMATCH=<n>`；
2. **只读语义**：向 `ID` 写一个值，必须**读回不变**（这是"RO 格真的只读"的判据）；
3. **负对照**（必须响）：把期望向量里**一格**改掉，断言 mismatch **恰好 1**。

退出码：`0` 过，`1` 不符，`2` 负对照没抓住（判据是橡皮图章）。
